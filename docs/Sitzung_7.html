Subjektrelativsätze: \(lz = Normal(471-102, \sigma)\)

Objektrelativsätze: \(lz = 471 \times 1 + (-102 \times 0) + \epsilon\)

Objektrelativsätze sind als 0 kodiert, Subjektrelativsätze als 1

Die allgemeine Formel lautet: \(rawRT=\beta_{0}+\beta_{1}condition+\epsilon\)

Kategoriale Prädiktorvariablen

  • Kodierung von kategorialen Prädiktorvariablen wird contrast coding genannt.
  • theoretisch könnte man irgendwelche Zahlen den unterschiedlichen Werten zuordnen. Um das Modell aber besser interpretieren zu können, gibt es gewisse Standardkodierungen
  1. Treatment coding
  2. Sum coding

Kategoriale Prädiktorvariablen

Treament coding

  • Referenzlevel = 0 (Intercept)
  • die anderen Werte werden damit verglichen

(Was wir oben bereits getan haben)

Kategoriale Prädiktorvariablen

Sum coding

  • der Mittelwert (mean) ist die Referenz
  • die Werte werden mit dem Mittelwert verglichen
contrasts(data_gibson$condition) <- contr.sum(2) # Funktion für sum coding
contrasts(data_gibson$condition)
        [,1]
subjgap    1
objgap    -1
m3.lz <- lm(rawRT ~ 1 + condition, data = data_gibson)
m3.lz

Call:
lm(formula = rawRT ~ 1 + condition, data = data_gibson)

Coefficients:
(Intercept)   condition1  
     420.22       -51.14

Sum coding

Der Intercept ist jetzt der Mitellwert der Mittelwerte

data_gibson |>
    summarise(mean = mean(rawRT), .by='condition')

\(lz_{\text{Subjekt}} = 420.22 + (-51.14 \times +1) = 368.08\)

\(lz_{Objekt} = 420.22 + (-51.14 \times -1) = 471.36\)

Die angepassten Koeffizienten können nun wieder in die Funktion eingefügt werden:

\(val = 5.58 + (-0.109 \times \text{Smell}) + (-0.174 \times \text{Sound}) + (0.228 \times \text{Taste}) + (-0.0452 \times \text{Touch})\)

Wie kann man den Prognosewert von Sound berechnen?

Die allgemeine Formel:

\(val = \beta_{0} + (\beta_{1}\times \text{condition}_{1}) + ... (\beta_{n}\times \text{condition}_{n}) + \epsilon\)
